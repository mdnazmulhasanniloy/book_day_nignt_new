## Steps

1. Add `EndPoint.versionPolicy = /v2/app/version-policy` and a repository that reads `{minVersion, recommendedVersion, storeUrls}`.
2. At startup (splash) compare with the installed version. `package_info_plus` is NOT in `pubspec.yaml` today: add it (or read the version another way) and note the new dependency.
3. Below `minVersion`: block with an update-required screen and a `url_launcher` button to the store. If the request fails, let the app continue (fail open).
