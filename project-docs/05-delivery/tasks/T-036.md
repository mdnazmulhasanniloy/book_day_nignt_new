The controller now reads the validated query (it used to re-parse `lat`/`lng` itself).
- Conservative choices: the `city` text filter keeps working and combines with a centre (both apply); without a centre `genres` is still unfiltered (as before); `lat` without `lng` is not a centre; radius default stays 20 km. `backend/openapi.yaml` was not updated (T-034 did not add `radiusKm` there either).
- Open: the task says "module labels use the city actually applied", but the feed response has no labels or city fields, and no label text is defined in the docs, so none was added. Needs a client or Flutter decision on whether a label (and which text) is wanted.
