## Steps

1. Keep `GET /service-charge` and `GET /admin/service-charge` returning the legacy flat value from the GLOBAL fee rule (old app builds keep working and keep displaying what they computed).
2. Keep `POST /purchase/*` accepting the old request shape and returning the old response shape; the server charges by the resolved rules and the response `payment` object keeps `serviceChargeAmount`.
3. Golden tests freeze the old responses so any later change that alters them fails CI.
4. Document in ADR-012 that an old build may show a total that differs from the charge once rates change, which is why the gate (T-099) and the Flutter release go together.
