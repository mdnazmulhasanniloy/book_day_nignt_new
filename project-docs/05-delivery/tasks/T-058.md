## Steps

1. `POST /v2/quotes` (v2 router from T-027): requires a bearer token and stores `Quote.userId`; same payload as v1 plus whatever the spec lists.
2. v1 `POST /quotes` stays public and unchanged in shape, now rate limited with the T-019 limiter (429), and deprecated (headers added in T-027).
3. `POST /hosts/:id/contact`: when a valid optional token is present, store `HostContact.userId`; anonymous still works; rate limited (429).
