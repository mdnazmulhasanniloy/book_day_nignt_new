## Steps

1. Accept optional `organizerId` on event create/update: it must be the caller's own organizer profile, or (for a club owner creating an event with a collaborator) an organizer with an ACCEPTED collaboration request for that club; otherwise 403/422.
2. Return `organizer` identity (`id`, `name`, `avatar`, `isVerified`) on `GET /explore/{id}` when set (completes CR-13).
