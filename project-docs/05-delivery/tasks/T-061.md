## Steps

1. Implement the club overview with `range`, `timezone`, `payType (ALL|FREE|PAID)`, `category (ALL|TICKETS|TABLES|EXTRAS)`. Response separates orders, admissions, tables, extras, fees, commission and proceeds, plus a confirmed-bookings series bucketed by local day.
2. Only PAID orders; free orders counted as admissions with zero money. Aggregate in SQL from stored snapshots.
3. Scans, no-shows and attendance rate are NOT returned (CR-05 deferred); do not return zeros that look like data: omit the fields.
4. Isolation: an owner only sees their own sellerUserId rows.
