## Steps

1. Write the permission catalogue as code: pages (events, bookings, guest lists, check-in, revenue, refunds, team, payout settings, chat, reports, rates, payouts, roles) each with VIEW and MANAGE, plus sensitive actions (change payout destination, transfer ownership, refund Technical Fee, charge to club, change rates, manage admins, publish events).
2. Write `resolvePermissions({ userId, clubId?, country? })` returning the effective set from account role, club membership, platform staff row, grants and the stored `RolePermission` matrix; deny by default; no self-escalation (a member cannot grant above their own level).
3. Seed the default matrix from the client's role descriptions (Owner, General Manager, Event Manager, Reservations Staff, Organizer; Platform Admin, Manager, Country Manager, Staff). Document it in `ADR-008` so the client can review it.
