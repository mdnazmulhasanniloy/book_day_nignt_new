## Steps

1. `GET /admin/orders`: filters `status`, `serviceType`, `sellerUserId`, date range, search by order id or buyer email; paging with a max `limit`; uses `(status, createdAt)`. Read only.
2. `GET /admin/orders/{orderId}`: order, purchase children, attendees, amounts and applied rule ids, payment transactions, refund and refund request. Never return password hashes or full card data (only what the spec lists).
3. `GET /admin/refunds`: list with status filter and paging.
