## Steps

1. `POST /v2/admin/events/{eventId}/venue-dispute`: set the authorization to SUSPENDED, stop new sales on the event (purchase returns 409 EVENT_SALES_SUSPENDED), keep every sold ticket valid.
2. Set `decisionDueAt` to 2 working days after the dispute (Monday to Friday; the holiday calendar is an open client point and defaults to none).
3. If the event starts within 48 hours, notify admins as urgent immediately. Notify all ticket holders promptly. If the admin then cancels the event, route the refunds through the partner-cancellation path (Q10).
