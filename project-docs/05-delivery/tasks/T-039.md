## Steps

1. Create the migration folder `backend/prisma/migrations/<ts>_add_engagement_tracking/` and write the SQL by hand from `data-model.md` section 9, row 11. Update `schema.prisma` to match (`prisma migrate dev --create-only` is fine to scaffold; never `migrate reset`).
2. Create `EventInterest`, `UserRecentEventView`, `EventViewDaily` exactly as in `data-model.md` 8.2 (composite PK on `EventViewDaily`, unique `(userId, eventId)` on the other two).
3. Run the rehearsal script (T-002) from a clean restore. It must finish with exit code 0. Paste its summary (restore time, this migration's run time, backfill row counts, CHECK-violation counts) into the PR.
4. Update `data-model.md` (move this migration's text from section 8 to sections 2 to 6 only when the matching code ships) and `api-usage-map.md` if endpoints are affected.
