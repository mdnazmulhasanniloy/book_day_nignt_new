## Steps

1. Replace the pure owner-id checks on events, bookings, guest lists and check-in (`verify-ticket` and the v2 scan later) with `resolvePermissions`: owner keeps full access; General Manager club-wide operations; Event Manager only assigned events; Reservations Staff guest lists, bookings, check-in.
2. Return 404 (not 403) for events outside the member's assignment, using the T-012 not-found mapper, so existence is not revealed. Permission failures inside a visible object use 403 errorType PERMISSION_DENIED (not 401).
3. Keep the owner-only behaviour byte-identical for owners (golden tests).
