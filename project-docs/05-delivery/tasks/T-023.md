## Steps

1. Write a pure function `resolveRule({ ruleType, productCategory, eventId, sellerUserId, at })` plus a thin DB loader: candidates are rules with `effectiveFrom <= at` and (`effectiveTo IS NULL` or `effectiveTo > at`); pick scope EVENT, then CLIENT, then GLOBAL; then higher `priority`; then later `effectiveFrom`. Return the rule or null.
2. Add `computeAmount(rule, unitAmount, quantity)`: PERCENT or FIXED, `perUnit`, `minAmount`, rounding to 2 decimals half-up (use `Prisma.Decimal`, never JS floats).
3. No endpoint and no checkout change in this task.
