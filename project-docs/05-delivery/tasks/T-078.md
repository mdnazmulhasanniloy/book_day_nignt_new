## Steps

1. Pending-first list; decision dialog: approve (amount defaults to requested, cannot exceed the refundable gross shown, return-service-fee checkbox) or reject (note required); confirm before sending.
2. A decided request shows read-only. Show that inventory is not released on refund (Q9 default) in the dialog help text.
3. Use `DataState` (T-070) for loading, empty, error and success; add en and it strings; call only the endpoints named above, as written in the spec (no new backend work in this task).
