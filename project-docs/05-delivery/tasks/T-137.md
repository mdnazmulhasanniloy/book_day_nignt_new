## Steps

1. Create the refund in one orchestrated flow: refund the admission price, reverse the Service Fee share, retain the Technical Fee (customer-initiated), mark the refund PENDING until the processor confirms (refund webhook, T-067), then REFUNDED.
2. Use the fee allocation per item so partial and per-ticket refunds are exact. Idempotent per ticket.
