## Steps

1. `GET /v2/admin/role-permissions` returns the matrix; `PUT` replaces one role's levels (per page NONE, VIEW or MANAGE, and sensitive toggles). `GET/POST /v2/admin/platform-staff` manage staff and country codes.
2. Changes take effect on the next request (no long cache) and write audit rows; Admin only.
3. Validation: unknown keys 422, Admin-only actions cannot be granted (T-108).
4. `GET /v2/admin/audit-log` lists the audit rows (filters actorId, action, from, to, page, limit at most 100), admin only; the page T-183 reads it.
