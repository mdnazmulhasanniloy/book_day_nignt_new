## Steps

1. Signup with `role: CLUB_OWNER` still succeeds (the live app lets the user choose it) but creates a PENDING `PartnerApplication` in the same transaction. A USER signup is unchanged.
2. Add the additive field `partnerStatus` (PENDING, APPROVED, REJECTED, or null for non-partners) to the user object in the signup, login, social, check and refresh responses. Do not remove or rename any field.
3. Organizer profile creation (`POST /organizer/profile`) also requires an APPROVED application, otherwise it creates or reuses a PENDING one.
4. A pending account never receives a 401 or 403 from this task: login and check succeed and report `partnerStatus: PENDING`.
5. Existing owners (APPROVED by T-080) see no change in any response except the new field.
