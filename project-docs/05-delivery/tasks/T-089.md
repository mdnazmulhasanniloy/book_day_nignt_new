## Steps

1. Create the v2 router if it does not exist (T-027) and add public `GET /v2/app/version-policy?platform=ios|android` returning `{ minSupportedVersion, latestVersion, storeUrl, feeModelV2Required }` from a settings row (`AppVersionPolicy` per platform, part of migration 22 or its own tiny migration).
2. Admin may set the row through the existing admin settings pattern (PATCH `/v2/admin/app-version-policy`), audit logged. Default row: minimum 0.0.0 (nobody is blocked).
3. Cache-Control short (60 s); no authentication.
