## Steps

1. Add `EndPoint.checkoutPreview = /v2/checkout/preview` and call it whenever quantity, tier, promo or extras change; show the lines in the order the server returns them and the display mode (itemized Technical Fee line, or included).
2. Label the customer fee "Technical Fee" in the app texts; the response field `serviceChargeAmount` keeps its name.
3. The payment amount must come from the order created by the server, never from the preview alone.
