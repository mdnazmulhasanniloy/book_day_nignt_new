## Steps

1. Add `group=day` (buckets Today, Tomorrow, This Weekend, Upcoming) computed in the city's timezone when `cityId` is given, else the event's own `timezone`. Weekend = Friday 18:00 to Sunday end in that timezone (state the rule in the spec).
2. Add `from` and `to` (ISO dates, local to the same timezone rule) and `dateFilter=this_week` (Monday to Sunday).
3. Add `total` to the list meta (count of all matches ignoring paging, same filters).
4. Chronological default ordering by `startAt` (index `(eventStatus, startAt)` already exists).
