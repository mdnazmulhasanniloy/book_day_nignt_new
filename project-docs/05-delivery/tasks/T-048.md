## Steps

1. Create the migration folder `backend/prisma/migrations/<ts>_add_organizers_collaboration/` and write the SQL by hand from `data-model.md` section 9, row 9. Update `schema.prisma` to match (`prisma migrate dev --create-only` is fine to scaffold; never `migrate reset`).
2. Create enum `CollaborationStatus` and tables `OrganizerProfile`, `OrganizerFollower`, `CollaborationRequest`; add `Event.organizerId` (FK SET NULL) with an index.
3. Raw SQL: partial unique index so there is at most one PENDING request per `(organizerId, clubId, COALESCE(eventId, '00000000-0000-0000-0000-000000000000'))`.
4. No backfill: existing `Event.clubHostStatus` values are not converted.
5. Run the rehearsal script (T-002) from a clean restore. It must finish with exit code 0. Paste its summary (restore time, this migration's run time, backfill row counts, CHECK-violation counts) into the PR.
6. Update `data-model.md` (move this migration's text from section 8 to sections 2 to 6 only when the matching code ships) and `api-usage-map.md` if endpoints are affected.
