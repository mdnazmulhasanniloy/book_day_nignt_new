## Steps

1. `POST /organizer/profile`: only an authenticated `CLUB_OWNER` without a profile (one profile per user; second returns 409). `PUT` updates own profile. `GET /organizers/{id}` is public and hides suspended profiles (404).
2. No new role value (ADR-002). Do not add any approval step (D1 is deferred); `isVerified` is set by admin later (T-053).
3. Validate `website`, `socialLinks` (known keys, URL format), `tags` (max count).
