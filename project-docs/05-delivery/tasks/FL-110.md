## Steps

1. Keep each ticket tier `id` in the owner edit model and send it on `PUT /event/{id}` so sold counts survive an edit (tiers without id are new).
2. Show the server message for 404, 409 and 422 on owner event calls (these used to be 500); note `payload shape` rule in `flutter_app/CLAUDE.md`: sub-resource bodies of modules and hosts must still not include `id`; tiers are the documented exception, check the spec.
