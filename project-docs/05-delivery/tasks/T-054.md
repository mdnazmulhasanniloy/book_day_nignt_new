## Steps

1. Create the migration folder `backend/prisma/migrations/<ts>_add_extras_module_pricing_quote_user/` and write the SQL by hand from `data-model.md` section 9, row 8. Update `schema.prisma` to match (`prisma migrate dev --create-only` is fine to scaffold; never `migrate reset`).
2. Create enum `ModulePricingType`, tables `EventExtra` (CHECK `price >= 0`, `0 <= remaining <= quantity`) and `EventExtraPurchase` (many rows per order; RESTRICT FKs), `EventModule.pricingType NOT NULL DEFAULT 'FIXED'`, `Quote.userId` and `HostContact.userId` (FK SET NULL, indexed).
3. Backfill: `pricingType = FIXED` for all existing modules (the column default does it); `userId` stays NULL for old quotes and inquiries.
4. Run the rehearsal script (T-002) from a clean restore. It must finish with exit code 0. Paste its summary (restore time, this migration's run time, backfill row counts, CHECK-violation counts) into the PR.
5. Update `data-model.md` (move this migration's text from section 8 to sections 2 to 6 only when the matching code ships) and `api-usage-map.md` if endpoints are affected.
