## Steps

1. On `payment_intent.succeeded` (and charge updates) fetch the balance transaction and store `processorFee` and `processorFeeCurrency` on the `OrderPayment` or PaymentTransaction row, never inside the customer fee or commission columns.
2. Add `issuanceCost` (nullable, per issued ticket, filled later by a fiscal provider) to the ticket row so the model exists; no provider is called here.
3. Idempotent on duplicate webhooks.
4. Expose the stored costs read-only in the v2 financials report (T-028 adds a separate line).
