## Steps

1. Authorize the card for the quoted amount (manual capture): show the request as Pending, release status on reject, "payment failed, retry" if capture fails, and the fresh-payment request after acceptance when the hold is unsupported or expired.
2. Confirmed is shown only after the server says the capture succeeded.
