## Steps

1. Accept optional `extras: [{ extraId, quantity }]` on `POST /purchase/module`. In one transaction: lock each extra, check `remaining`, decrement it, create `EventExtraPurchase` rows with `unitPrice` and `extraName` snapshots, and add the sum to `grossAmount`.
2. Apply the EXTRA COMMISSION rule (T-023); no FEE rule for EXTRA until Q2 is answered.
3. Release extras stock when the module order fails or expires: extend the existing module hold-expiry job and the payment-failed webhook handler, idempotently (same guard as T-007).
4. Included people (`peopleIncluded`) are informational only in this task.
