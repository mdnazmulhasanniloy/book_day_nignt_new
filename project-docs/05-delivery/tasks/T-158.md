## Steps

1. `POST /v2/venue-authorizations`: an organizer with a profile submits eventId, venue name and address, the accepted form version and evidence urls (urls must be files the caller uploaded via `/media`). Creates PENDING.
2. An event with a manual (unregistered) venue cannot be published and its purchase endpoints return `409 VENUE_NOT_AUTHORIZED` until the authorization is APPROVED.
3. Registered-club events are unchanged (no check).
