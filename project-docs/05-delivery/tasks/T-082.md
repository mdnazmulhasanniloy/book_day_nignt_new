## Steps

1. Add `requirePartnerApprovedMiddleware`: for a user with a non-APPROVED application it answers HTTP 423 with `{ success: false, errorType: 'PARTNER_APPROVAL_PENDING' or 'PARTNER_APPLICATION_REJECTED', partnerStatus, message, traceId }`. It must never answer 401 or 403.
2. Apply it to every partner endpoint: `/club*`, `/event*`, `/owner/*`, `/organizer/*`, `/promo` management, `/connect/*`, `/media` upload for partners. Allowlist the calls the club-area home uses (`GET /auth/check`, the profile read, notifications read) so a pending owner sees only the club-area home; there is no separate home endpoint.
3. The check reads the status in the same query that loads the user (no extra round trip per request) and caches nothing across requests.
4. Customer endpoints stay open to every account; a person who wants to buy as a customer needs a separate customer account (Q22), the rule is documented in ADR-010.
