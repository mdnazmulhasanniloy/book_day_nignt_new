## Steps

1. Add a Redis-backed limiter middleware (fixed window, 20 requests per minute) keyed by IP and, when a valid token is present, by user id. Reuse the OTP limiter's helper if it is generic; otherwise add a tiny generic one in `src/app/middlewares/`.
2. Return 429 with `Retry-After` seconds and a stable `errorType` (`RATE_LIMITED`). Take the limit from a constant, not a literal in the route.
3. Make sure the IP comes from the trusted proxy header the app already uses (check `trust proxy` in `app.ts`); otherwise every request shares one key.
