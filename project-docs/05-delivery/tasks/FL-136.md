## Steps

1. Extend the existing owner Promo tab into one code screen: choose purpose (discount or guest-list request), event or list, expiry and use limit (1 = single-use, 100 = shared code).
2. List the owner's codes with remaining uses and expiry; the old promo screens keep working for old data.
3. Respect the server permission result: staff roles without the permission see the list read-only (role fields from T-110).
