## Steps

1. In `POST /purchase/event`, when a tier is chosen, write `ticketTierId` and `ticketTierName` (snapshot) on the `EventPurchase` row inside the same transaction that increments `soldCount`. No-tier purchases keep both NULL.
2. Return `ticketTierId` and `ticketTierName` on the purchase response and on `GET /bookings/{id}` for event bookings (additive fields; NULL for old purchases).
3. Keep the existing capacity check and `soldCount` increment unchanged (still increments at order creation; the release comes in T-007 and T-008).
4. Update the spec rows and `api-usage-map.md`.
