## Steps

1. Create migration `<ts>_add_team_roles_permissions`: `ClubTeamMember` (clubId, userId, role GENERAL_MANAGER, EVENT_MANAGER, RESERVATIONS_STAFF; status INVITED, ACTIVE, SUSPENDED; invitedBy, token hash, assigned event ids via `ClubTeamMemberEvent`), `PlatformStaff` (userId, role PLATFORM_MANAGER, COUNTRY_MANAGER, PLATFORM_STAFF, `countryCodes text[]`), `RolePermission` (scope CLUB or PLATFORM, role, permission key, level NONE, VIEW, MANAGE), `PermissionGrant` (organizer grants for quotes, chat, refunds with grantedBy, grantedAt, revokedAt), `PermissionAuditLog`.
2. Do NOT touch the `AccountRole` enum (USER, ADMIN, CLUB_OWNER): staff and platform roles are separate tables.
3. Unique `(clubId, userId)` for active members; CHECK Country Manager rows have at least one country code.
4. Seed no members; seed the default `RolePermission` matrix only after T-102 defines it.
