## Steps

1. The columns for the percent part, `fixedValue`, `fixedCurrency`, `fixedOncePerOrder` and the scopes COUNTRY, VENUE and TABLE_QUOTE are created by migration 6 in T-022 (it is not written yet, so no extra migration). This task adds the behaviour on top of them; the `display` hint stays with T-097.
2. Resolver (T-023): precedence TABLE_QUOTE, EVENT, CLIENT, VENUE, COUNTRY plus category defaults, GLOBAL last; `computeAmount` returns percent amount per item and the fixed part once per order; `Prisma.Decimal` only.
3. Per-currency fixed amount: the rule stores one fixed amount per currency (EUR 0.50 seeded; the USD amount is set by an admin, no live exchange rate). An order in a currency without an amount is refused with a configuration error.
4. Seed launch defaults for IT, FR, MC, ES, US: Technical Fee 5% + EUR 0.50 once per order; Service Fee (COMMISSION) 10% TICKET, 15% TABLE and EXTRA. Free admissions: fee 0, commission 0, optional partner fixed charge rule disabled.
5. Terminology: FEE rows are the customer Technical Fee, COMMISSION rows are the partner Service Fee; DB and API names are unchanged.
