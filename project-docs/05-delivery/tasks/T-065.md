## Steps

1. The seller (owner of the order) can request a refund: `reason` required, `requestedAmount` optional (null = full). Order must be PAID and have no existing Refund (one refund per order) and no PENDING request (409).
2. `requestedAmount` must be > 0 and <= refundable gross (422 otherwise). Do not support per-attendee refunds (Q8 default B: whole order, or an amount once).
3. Create `REFUND_REQUESTED` notifications for admins (and an in-app record for the owner).
4. Stock is NOT released on a refund request or approval (Q9 default: no).
