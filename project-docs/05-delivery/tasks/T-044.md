## Steps

1. `GET /artists` (search, paging, follow state when a token is present) and `GET /artists/{id}` (profile with `photo`, `bio`, `socialLinks`, upcoming events).
2. `PATCH /artists/{id}` for the club owner or organizer who manages the artist (define 'manages' as: created the artist or has an event with that artist in the lineup; say which in the PR). Admin `GET` and `PATCH` (edit, verify) on `/admin/artists`.
3. Lineup items on `POST /event` and `PUT /event/{id}` accept optional `artistId` to link an existing artist.
