## Steps

1. Implement `GET /v2/admin/financials` as in the spec: range and grouping parameters, customer fees, Bookdia commission and seller proceeds reported separately (never summed into one 'fee').
2. Aggregate in SQL (`SUM` on stored Order snapshots; never recompute from current rules). Only PAID orders; refunds are shown as a separate line when Refund rows exist.
3. Use the `(status, createdAt)` and `(sellerUserId, status, createdAt)` indexes only if migration 13 has shipped; otherwise restrict the maximum range (for example 366 days) and note it.
