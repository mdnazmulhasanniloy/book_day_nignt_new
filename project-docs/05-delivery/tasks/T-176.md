## Steps

1. Add "Roles and permissions": a matrix of roles (club and platform) by page with View and Manage checkboxes, plus a list of sensitive-action toggles; save with `PUT /v2/admin/role-permissions`. Only an Admin may edit; others see it read-only.
2. Add the platform staff list and create form (Platform Manager, Country Manager with a country or region, Platform Staff) using `GET` and `POST /v2/admin/platform-staff`.
