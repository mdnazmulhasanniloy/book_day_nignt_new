## Steps

1. `GET /admin/partner-applications` (filters `status`, `kind`, search, paging), `POST /admin/partner-applications/{id}/approve` and `/reject` (note required on reject). Use the admin cookie, role and CSRF chain.
2. Deciding sets `decidedAt`, `decidedByAdminId`, `decisionNote` in one transaction; deciding twice returns 409.
3. Send a notification (email and in-app, using the existing helper) to the applicant on both outcomes.
4. Write one audit row per decision (admin id, application id, outcome, note).
