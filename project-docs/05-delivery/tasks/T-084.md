## Steps

1. Write `backend/server/scripts/backfill-event-timezone.ts` (dry run by default, `--apply` to write): for each event with `timezone = 'UTC'` and `timezoneSource IS NULL`, derive the IANA zone from the nearest launched `City` within its radius, else from the club's city, else from lat/lng via the City table. Never change `startAt` or `endAt` (instants stay identical).
2. Records that match more than one zone, or none, are not written; they go to a CSV `ambiguous-timezones.csv` (event id, name, candidates).
3. Organizer correction already exists through `PUT /event` (T-017); add nothing new there.
4. Refuse to run unless the database name matches `*_test`, `*_rehearsal` or `--i-have-approval` is passed with a database host that is not production by name; log every change with the old and new value.
