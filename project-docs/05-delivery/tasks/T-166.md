## Steps

1. `GET /v2/bookings/{id}/chat` (messages, paging, read state) and `POST /v2/bookings/{id}/chat`. Allowed: the customer, the club owner, staff with the chat permission and organizers whose owner granted chat (T-106). Everyone else gets 404 (not 403, so existence is not revealed).
2. Rate limit and a maximum body length; messages are stored in the booking language of the sender; closed conversations are read-only.
