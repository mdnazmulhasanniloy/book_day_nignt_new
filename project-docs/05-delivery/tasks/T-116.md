## Steps

1. Venue `/accept` captures the authorization before `captureBefore` (a scheduled reminder job warns the venue 24 h and 2 h before). Success: order CONFIRMED, table reserved (T-114), customer notified.
2. Capture failure (expired, declined): release the table, set status CAPTURE_FAILED, notify the customer with a retry route to the fresh-payment flow (T-117).
3. Only a successful capture creates the PAID order and the ticket; no confirmation before that.
