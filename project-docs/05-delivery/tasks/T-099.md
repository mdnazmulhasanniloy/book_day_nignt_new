## Steps

1. Add a switch `feeModelV2Active` (setting row, admin only). While off, checkout charges with the legacy flat fee rules and ignores the new percent rules; while on, the new rules apply.
2. The switch can be turned on only if `AppVersionPolicy.minSupportedVersion` for both platforms is at or above the first build that uses the preview endpoint (setting `feeModelV2MinBuild`); otherwise 409.
3. Log every switch change with admin id and time; show current state in the admin settings response.

## Done when

- [ ] Test: turning it on with a too-low minimum version returns 409.
