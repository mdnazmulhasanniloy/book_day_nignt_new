## Steps

1. Owner-only create, update and delete for events the caller owns (404 otherwise, via T-012 mapper); public `GET` lists active extras by `sortOrder`.
2. `quantity` and `remaining`: on create `remaining = quantity`; on update changing `quantity` adjusts `remaining` by the same delta and never below 0 (422 if it would).
3. DELETE: delete if no `EventExtraPurchase` references it, else deactivate (`isActive = false`) and return which happened.
