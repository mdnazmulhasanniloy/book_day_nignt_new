## Steps

1. On a confirmed booking create `LedgerEntry` rows per payee in state PENDING with the allocation per item (from the fee allocation task); keep admission and scan status separate from settlement status.
2. At event end move entries to CONFIRMED with `expectedTransferDate = eventEnd + 3 calendar days`. A no-show alone never changes the state.
3. Expose the state and date on the owner and admin settlement reads.
