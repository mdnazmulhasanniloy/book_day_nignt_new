## Steps

1. Add Vitest and Testing Library (dev dependencies, `npm test` script, `vitest.config.ts` reusing the Vite config); add one example component test.
2. Add shared components under `admin/src/components/data/`: `DataState` (loading skeleton, empty, error with retry, success), `PagedTable` wrapper over the existing `ui/table`, `StatusBadge`, `ConfirmDialog`. Every new page must use `DataState`.
3. Add the route entries and sidebar groups for the new pages (Discovery: Cities, Filter options, Artists; Organizers: Organizers, Collaboration requests; Finance: Pricing rules, Financials; Orders: Orders, Refund requests, Refunds). Pages are placeholders until their own task.
4. Add the i18n key namespaces in `en.json` and `it.json` (both languages for every key; no hard-coded strings in new pages).
5. Confirm the axios config handles the CSRF header and `/api/v2` base for the new endpoints (the v2 pricing-rules and financials calls use `/api/v2`).
