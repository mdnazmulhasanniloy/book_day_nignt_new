## Steps

1. Add a role check (`accountRole = CLUB_OWNER`; 403 otherwise) on create, update and delete.
2. Add ownership: the `eventId` or `clubId` on the code must belong to the caller; a global code (neither id) can be created, updated or deleted by an ADMIN only. Not owned: 404 (same as unknown, no information leak).
3. Unknown `eventId` or `clubId` on create/update returns 404 (use the T-012 mapper), not 500.
4. Re-check `promo_repository.dart` usage in `flutter_app` (read-only) to confirm only the owner Promo tab calls these routes (the diff doc already says so; record the file and line in the PR).
