## Steps

1. Create the `/api/v2` Express router (first v2 module in the repo; mount it once, reuse v1 services). Add `GET/POST /v2/admin/pricing-rules` and `PATCH /v2/admin/pricing-rules/:id`.
2. POST: validate with the CHECK rules (value >= 0; percent <= 100; scope/scopeId pairing; `effectiveTo > effectiveFrom`); a new rule's `effectiveFrom` must be now or later; store `createdByAdminId`. Unknown scope target returns 404.
3. PATCH: allowed changes are `effectiveTo` (end-dating) always, and `value`/`priority` only while `effectiveFrom` is in the future; anything else returns 409.
4. GET: filters `ruleType`, `productCategory`, `scope`, `active`, paging.
5. Add the `Deprecation: true` and `Link: <v2 url>; rel="successor-version"` headers to the six deprecated v1 operations (`/quotes`, `/admin/commission` GET and PATCH, `/service-charge`, `/admin/service-charge` GET and PATCH). Behaviour otherwise identical.
