## Steps

1. Find every write path of `Event` and `Club` that sets lat/lng (create, update, duplicate, seed scripts) and make each set `geog` in the same statement or transaction.
2. `POST /event/{id}/duplicate` must copy or recompute `geog`.
3. Add a DB-level safeguard only if it is cheap (a trigger that sets `geog` from lat/lng on insert/update): if you add one it is a new migration with its own rehearsal run; otherwise keep it in code and add the check query to the rehearsal.
