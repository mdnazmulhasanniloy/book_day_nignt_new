## Steps

1. Add `eventModulePurchase` (tables) to the where clause of `GET /owner/earnings`.
2. Replace the fixed CST day boundaries with a shared helper `dayBounds(date, timezone)` (dayjs timezone plugin) using the `Event.timezone` for per-event figures and a `timezone` request parameter (default the club's city timezone or UTC) for club-level figures. Put the helper in `src/app/utils/time.utils.ts` for reuse by T-061.
3. Do not remove or rename any response field; totals will be higher (client notice 1). Record before/after totals on the rehearsal DB for 3 owners and put them in the PR.
