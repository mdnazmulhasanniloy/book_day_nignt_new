## Steps

1. Read the additive `partnerStatus` from signup, login and check responses. When PENDING, route the user to a pending-approval screen (club-area home with partner tools locked) instead of the payout setup.
2. Handle HTTP 423 `PARTNER_APPROVAL_PENDING` from any partner call by showing the pending screen. It must never clear the session: only 401 does (see FL-B07).
3. Signup copy: tell new owners and organizers that approval is required and that customer use needs a separate customer account.
