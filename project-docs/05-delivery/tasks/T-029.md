## Steps

1. Create the migration folder `backend/prisma/migrations/<ts>_backfill_geog/` and write the SQL by hand from `data-model.md` section 9, row 3. Update `schema.prisma` to match (`prisma migrate dev --create-only` is fine to scaffold; never `migrate reset`).
2. Write the data-only migration: `UPDATE "Event" SET geog = ST_SetSRID(ST_MakePoint(lng, lat), 4326)::geography WHERE geog IS NULL AND lat IS NOT NULL AND lng IS NOT NULL;` and the same for `Club`. Check the real column names in `schema.prisma` first (the SQL in the doc is a template).
3. Count affected rows before and after in the rehearsal backfill-counts query.
4. Run the rehearsal script (T-002) from a clean restore. It must finish with exit code 0. Paste its summary (restore time, this migration's run time, backfill row counts, CHECK-violation counts) into the PR.
5. Update `data-model.md` (move this migration's text from section 8 to sections 2 to 6 only when the matching code ships) and `api-usage-map.md` if endpoints are affected.
