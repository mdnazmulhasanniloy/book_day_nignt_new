## Steps

1. Add "Partner approvals" (Accounts group): list with status filter (PENDING default), applicant role (owner or organizer), club or organizer name, date; approve and reject with a required note on reject, through `ConfirmDialog`.
2. Show a banner that existing owners are already approved (migration backfill) so an empty queue is not alarming.

## Done when

- [ ] Test: approve calls POST approve once; reject without a note is blocked and a 422 is shown if it reaches the server.
- [ ] Test: a 409 (already decided) refreshes the row; empty, error and success states render.

- [ ] Manual check on staging with a real admin session: each state is reachable (empty list, a forced error, success).
