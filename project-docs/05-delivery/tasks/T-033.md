## Steps

1. `GET /cities` (public): search by `q` (prefix, case-insensitive), `launchedOnly`, paging, sorted by name. Return `id`, `name`, `countryCode`, `lat`, `lng`, `timezone`, `isLaunched`.
2. Admin: list, create, and `PATCH` (name, coordinates, timezone, `isLaunched`). Unique `(name, countryCode)` violation returns 409. Validate IANA timezone.
3. Admin routes use the existing admin auth and CSRF chain exactly as `x-auth` in the spec shows (note S-22: be consistent on the CSRF header).
