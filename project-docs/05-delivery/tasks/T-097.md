## Steps

1. Add `FeeDisplayRule` (market country, product category, mode ITEMIZED or INCLUDED) read by the preview; default ITEMIZED everywhere, INCLUDED for US consumer ticket listings once the client confirms (open question).
2. In INCLUDED mode the listed price and the preview total contain the Technical Fee and the label is 'Service fee included' (client wording in the preview `labels` field); the amount is still stored separately.
3. Event list and event page endpoints get an additive `displayPrice` computed with the same rule (v2 shape only; v1 price fields unchanged).
