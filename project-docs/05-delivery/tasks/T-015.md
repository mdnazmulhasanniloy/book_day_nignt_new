## Steps

1. Create the migration folder `backend/prisma/migrations/<ts>_add_event_timezone_pricing_mode_tier_type/` and write the SQL by hand from `data-model.md` section 9, row 4. Update `schema.prisma` to match (`prisma migrate dev --create-only` is fine to scaffold; never `migrate reset`).
2. Add `Event.timezone TEXT NOT NULL DEFAULT 'UTC'`, enums `PricingMode` and `TierType`, `Event.pricingMode NOT NULL DEFAULT 'SINGLE'`, `EventTicketTier.tierType NOT NULL DEFAULT 'TICKET'`.
3. Backfill `pricingMode`: TIERED where the event has at least one tier; else FREE where `eventPrice = 0`; else SINGLE. `tierType`: TICKET for all existing tiers (no name heuristic).
4. Add the migration 4 review query (from `data-model.md` section 9) to the rehearsal output so the product owner can pick which tiers become PASS by hand.
5. Run the rehearsal script (T-002) from a clean restore. It must finish with exit code 0. Paste its summary (restore time, this migration's run time, backfill row counts, CHECK-violation counts) into the PR.
6. Update `data-model.md` (move this migration's text from section 8 to sections 2 to 6 only when the matching code ships) and `api-usage-map.md` if endpoints are affected.
