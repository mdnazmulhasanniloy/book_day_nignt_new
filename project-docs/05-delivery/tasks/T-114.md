## Steps

1. Reserve the table atomically on acceptance: `SELECT ... FOR UPDATE` on the module slot plus the partial unique index from T-112; a second acceptance or a direct fixed-price purchase for the same table and slot fails with 409 `TABLE_UNAVAILABLE`.
2. A request alone reserves nothing (Q1 answer 1); a hold is only taken at acceptance and released when payment fails, the hold expires or the quote is withdrawn.
3. Direct purchases (`POST /purchase/module`, FIXED) use the same lock.
