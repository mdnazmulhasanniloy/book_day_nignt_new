## Steps

1. `POST /admin/auth/refresh`: throw with `statusCode: 401` (not `status`) and `errorType` `TOKEN_INVALID` or `TOKEN_EXPIRED`.
2. `PATCH /admin/users/:id/suspend`: unknown id returns 404 (`statusCode`), not a plain Error.
3. `GET /admin/users` and `GET /admin/earnings`: validate `page` and `limit` with a Zod query schema (positive integers, `limit` max 100); invalid returns 422 through `validateReqBody`-style handling. Defaults unchanged when absent.
4. Do not change success shapes.
