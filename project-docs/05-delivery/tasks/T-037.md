## Steps

1. `GET /explore/filters?type=EVENT|CLUB`: categories, genres, moods (active `FilterOption` rows ordered by `sortOrder`).
2. Admin: list, create (labelKey derived: lowercase and trim; duplicate returns 409), `PATCH` label, `sortOrder`, `isActive`. Deactivating a value never edits existing events.
3. `GET /explore/genres` stays exactly as it is for existing clients.
