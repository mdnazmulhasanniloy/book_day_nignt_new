## Steps

1. List with filters (type, category, scope, active); create form (type FEE/COMMISSION, category, scope with a target picker for CLIENT/EVENT, percent or fixed value, per unit, min amount, priority, effective from); end-date action; edit only for future rules.
2. Show the precedence rule (event > client > global, then priority, then latest start) as help text. The existing Settings commission form stays (it uses the deprecated v1 endpoints that write through); add a note there pointing to this page.
3. Use `DataState` (T-070) for loading, empty, error and success; add en and it strings; call only the endpoints named above, as written in the spec (no new backend work in this task).
