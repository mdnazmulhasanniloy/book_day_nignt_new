## Steps

1. Add `PlatformStaff` authentication: platform managers, country managers and staff sign in to the admin app through the existing admin login but with their own `PlatformStaff` row (the `AccountRole` is not extended; they use a USER or ADMIN-compatible session flag documented in ADR-008).
2. Declare a required permission and country scope on every `/admin/*` route; a Country Manager's lists and writes are filtered to their country codes in SQL (events, clubs, cities, orders by event country).
3. Platform Staff: refunds within policy, tickets, chat, reports, disputes; no rates, payouts, roles, event publishing.
