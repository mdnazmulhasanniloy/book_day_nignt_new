## Steps

1. `GET /v2/admin/chats` (flagged filter, event, club), message read, and `POST /v2/admin/chats/{id}/intervene` (post a message labelled Bookdia Night, or close the conversation).
2. Allowed: Admin and platform staff with the chat permission, within their country limit. Every read and intervention is written to the audit log.
