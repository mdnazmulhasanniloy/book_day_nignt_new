## Steps

1. Implement `GET` and `PUT /v2/events/{eventId}/settlement`: only an admin sets the Bookdia share (equal to the Service Fee rule); the owner proposes the remaining split between club and organizer; amounts are visible only to the parties and admin.
2. Implement `POST /v2/events/{eventId}/settlement/accept` for the organizer. Sales cannot open (publish with paid tiers) until the arrangement is ACCEPTED or the event has no organizer.
3. Select the settlement mode before sales open; a later change is refused once the first order exists.
