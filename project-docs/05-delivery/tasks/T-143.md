## Steps

1. On an eligible cancellation (unused and invalidated, or an approved late cancellation) return the place to the tier while sales are open and before the club's sales end; stop on cancelled events.
2. Add `POST /v2/owner/events/{eventId}/restock` (manual; notifies the owner when manual release is required) with a guard against double release (one release per ticket).

## Done when

- [ ] Test: an in-time cancellation increases availability by one; a scanned ticket does not.
- [ ] Test: after the sales end time nothing is restocked and the owner is notified.
- [ ] Test: a manual restock of the same ticket twice releases once.
- [ ] Test: a cancelled event never restocks.
- [ ] `npm run lint`, `npm run build` and `npm test` (in `backend/server/`, and `worker/` or `scheduler/` if touched) are green; DB-backed tests green with `npm run test:db`.
