## Steps

1. On each order store the rates used and a per-item allocation: for every purchased item (`EventPurchase`, module, extra) the Technical Fee percent amount, the share of the once-per-order fixed amount (proportional to item subtotal, remainder to the largest item) and the Service Fee.
2. Persist as rows in a new `OrderFeeAllocation` table (order, item type, item id, tech fee, fixed share, service fee), written in the checkout transaction. Totals must equal the order columns exactly.
3. Later rule changes never touch stored allocations (snapshot).
