## Steps

1. Write `backend/server/scripts/correct-sold-count.ts`: input is one event id and the approved paid count; it sets `soldCount` to the paid count of the tier only if the stored value still equals the value in the report, in one transaction, and writes an audit row (who, when, old, new, approval reference).
2. It refuses to run without `--approval <reference>` and without a matching entry in an approvals file the client's written OK is copied into.
3. Dry run prints what would change. One event per run.
