## Steps

1. List every DELETE route that passes `validateReqBody(...)` (grep). For each, check in `api-usage-map.md` and the Flutter and Admin code whether the client actually sends the body the schema expects.
2. Make `validateReqBody` run for DELETE when a schema is explicitly passed (keep the current behaviour for GET/HEAD). Apply to `DELETE /media` first.
3. Because the live Flutter app may send DELETE without the body some routes now require, ship each affected route only after the check in step 1; list routes where the client does not send the body and leave them out (report in the PR).
4. S-01 (no auth on `/media`) is a separate open item and is not changed here.
