## Steps

1. POST (organizer to a club, optional `eventId`, message): the club must exist; duplicate PENDING returns 409 (catch the partial unique violation).
2. GET: an organizer sees own requests; a club owner sees requests to their clubs; filter by `status`.
3. PATCH: the club owner can ACCEPT or REJECT (with `responseNote`), the organizer can CANCEL their own PENDING request; any other transition returns 409. Set `respondedAt` and `respondedByUserId`.
4. Send `COLLABORATION_REQUESTED` to the club owner and `COLLABORATION_RESPONDED` to the organizer (reuse the notification helper).
5. Accepting does NOT auto-assign an event; it records the agreement only (payout split is Q3, unregistered venues Q4: not built).
